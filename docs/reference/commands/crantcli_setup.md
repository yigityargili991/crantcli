# crantcli setup

Set or update API tokens (SeaTable and CAVE)

## Synopsis

Interactively set or update the SeaTable API token and optional CAVE token stored in ~/.crantcli/.

```
crantcli setup [flags]
```

## Options

```
  -h, --help   help for setup
```
